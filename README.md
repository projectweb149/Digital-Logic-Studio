# Digital Logic Studio
DESIGN. SIMULATE. VERIFY. LEARN.

A single-file digital electronics simulator (no build step, no dependencies).

Features: logic gates, adders/subtractors, ripple-carry adder (2–8 bit), MUX/DEMUX, decoders, priority encoder, comparator, Gray converters, parity generator, flip-flops, counters, truth tables (CSV copy), timing waveforms, Verilog and testbench generation, JS reference-model self-test.

Note: generated Verilog has not been compiled or simulated in an HDL simulator.

## Deploy on GitHub Pages
1. Create a new GitHub repository and upload `index.html` and `README.md`.
2. Go to Settings, then Pages.
3. Under Build and deployment, choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. After about a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Run locally
Open `index.html` in any browser.
